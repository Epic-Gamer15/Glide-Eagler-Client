# Server
the server is a little more complicated as it uses a external ip host cuz yes
ITS STILL FREE (and has better specs than eagler host <3 )
sign up to playit.gg
choose docker
copy secret key
add it as a github repo secret named PLAYIT_SECRET
make sure your playit account has a verified email 
set up a tunnel named whatever
configure it how you want
copy the ip/link from the top 
put it in mc
wait for it to load up and play!

you can configure server settings in the Server/folder
